# Connected edit redesign review

Antigravity `gemini-4-argon-high`, high effort, analyzed instrumentation baseline `44c674c` in branch `agent/agy/connected-analysis`. The integrator reviewed its source analysis and reworked the proposal below. No projected time from that consultation is presented as a measured result. Actual baseline spans and final results belong in [CONNECTED_SOLID_BENCHMARK.md](CONNECTED_SOLID_BENCHMARK.md).

Measured priorities were edge-pair validation for Move; full-shell orientation followed by segment reinsertion and seam scans for push/pull. The completed 864-face reconstruction trace attributes 1.82 s to segment reinsertion, 171 ms to seam lookup, 1.35 ms to healing and 0.113 ms to face rebuilding. Global healing was not the dominant phase in that sample. Source review additionally found quadratic polygon deduplication. The R-tree already existed, but those loops did not use it.

Implemented design:

- Full validation uses conservative edge-envelope candidates, followed by the unchanged tolerance-aware intersection predicate. This also improves load-time validation. It is still a full diagnostic operation, not part of every valid rigid translation.
- Whole-definition pure translations capture original positions/planes once and apply absolute offsets in key order. Replacing a preview reuses the originals. Undo restores original values rather than subtracting an offset, preserving exact geometry. R-tree coordinates use a runtime translation frame; topological maps remain unchanged. Other affine transforms and partial selections retain general validation.
- Dirty sets retain entity IDs and add a rigid-translation hint. The renderer keeps the existing definition mesh and changes its occurrence matrices. Later local mesh edits subtract the same render-frame offset, so neither a full triangulation nor a full buffer upload is needed after a translation. The hint never changes serialized values.
- Exterior support-plane extrusions build a small cap/wall delta and preserve untouched subdivision edges. The proof checks closed incidence and that old geometry is behind the starting plane; interior blind pockets additionally require coplanar neighbors and no other swept-prism surface. Hole-bearing models and collisions retain the general Boolean path. This is deliberately stricter than the consultation's general local-prism proposal; preservation of aperture semantics is covered by existing regressions.
- The general orientation traversal looks up only a face's boundary edges. Boolean surface construction uses an indexed vertex weld and segment intersection builder, seam queries use a segment R-tree, and polygon deduplication uses spatial centroid candidates with the existing exact comparison. These changes address the measured fallback bottlenecks without claiming that every complex Boolean now meets 16 ms.

The reference Boolean path dissolves coplanar grid seams, whereas local extrusion preserves untouched topology. Equivalence therefore compares closed incidence, volume, area and symmetric surface samples; translations also compare exact vertices/edges/IDs and geometric planes. Exact undo/cancel/redo remains a separate requirement. Tests exercise small subdivided cubes, outward extrusions, pockets, holes, repeated previews, translations followed by indexed edits, and translated renderer caches.

Limits: these fast paths prove specific invariants rather than accepting arbitrary unchecked deformations. Complex collisions, through cuts and hole-bearing shells still use the general Boolean path; their latency is not established by the support-face benchmark. The large regression measures raw geometry updates, not container placement. Full UI scheduling/picking/drawing remain separate from completed update-upload timings.
