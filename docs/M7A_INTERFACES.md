# M7a Styles and Scenes

Frozen serializable core values are in `presentation.rs`: `StyleMode`, `ViewStyle`, `SceneCamera`, `SavedScene`, `Presentation`. Archive v3 adds `DraftBundle.presentation: Presentation`; v1/v2 default it. Topology schema stays 1. Renderer consumes style as uniforms/pipeline state without rebuilding mesh buffers. Scenes capture camera, tag visible flags and explicit hidden flags keyed by definition/instance; stale IDs are ignored and new objects retain their current flags. Camera transition lasts 0.25 seconds and can be skipped. Section planes and shadows are excluded.

App module `presentation_ui.rs` owns capture/restore/scene management, transition and Styles/Scenes panel. Integration fields: `presentation: cindral_core::Presentation`, `presentation_ui: presentation_ui::PresentationUi`; call `presentation_panel(ctx)` and `transition_tick(ctx)` each frame. Renderer integration and file UI wiring remain integrator-owned. Style/scene edits call `presentation_changed()` (sets files.last_revision=None). Restore must use metadata visibility updates without replacing geometry/history. Unit/scripted tests belong in this app module.
