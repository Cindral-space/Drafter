# M5 frozen interfaces

Core serializable types are in `document_data.rs`: GeometryData (maps + next ID), DocumentData (schema_version=1, root, definitions, tags, materials), DefinitionData (local geometry + child instances), DefinitionKind Root/Group/Component, Instance (id/name/definition/local transform/tag/material/hidden), Material (linear RGB, opacity, optional texture slot). Typed IDs have a public u64 tuple field; geometry entity IDs retain from_raw/value. Runtime Model/History are not serialized. Face adds `material: Option<MaterialId>`; default None. Groups have private structurally-owned definitions; component definitions are shared. Nesting is a DAG with cycle/depth guards.

Runtime `DocumentHistory` will provide M4 History-compatible model/execute/preview/cancel_preview/commit_preview/undo/redo/revision/undo_depth/redo_depth/changes methods scoped to active context. `organization(OrganizationCommand)->Result<bool,KernelError>`, `enter(InstancePath)->Result<(),KernelError>`, `exit()->Result<bool,KernelError>`, `context()->&[InstanceId]`, `world_transform()->DMat4`, `active_definition()->DefinitionId`, `document_changes()->&DocumentChanges`, `occurrences()->Result<Vec<Occurrence>,KernelError>` (visible root + nested instances), `definition_model(DefinitionId)->Option<&Model>`, `to_data()->DocumentData`, `from_data(DocumentData)->Result<Self,KernelError>`, `tags()/materials()->&BTreeMap`, `instances(DefinitionId)->Option<&BTreeMap<InstanceId,Instance>>`, `definition_name/kind`, `instance(path)->Option<&Instance>`.

Geometry changes are delta history per definition; global history points to the edited definition, independently of context navigation. Entry/exit is navigation, not a geometry undo step. Undo removes invalid context suffixes. Visibility tags belong to container instances (loose topology remains untagged); material references can be applied to faces or inherited from nearest painted instance. Runtime scene/mesh caches stay outside DocumentData.
